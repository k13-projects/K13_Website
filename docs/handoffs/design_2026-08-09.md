# K13 Website — Brand DNA Assessment (2026-08-09)

Scope: assess-only. No files modified outside this handoff doc. Compared `README.md`'s
documented brand system against the live implementation in `index.html`, the print
collateral in `brand/print/`, the logo masters in `brand/logo/`, and the client subpage
`pricing/tiger/index.html`. Confirmed `public/styleguide.html` does not exist and scoped
what building one would need to cover.

## Finding 1 — the README describes a brand kit the live site no longer wears

`README.md` documents: Ink `#15130F`, Paper `#F1ECE2` / `#E9E1CF`, Cream-on-ink `#EFE9DC`,
Signal orange `#FF4F00`, Muted `#6F6755`; type = **Space Grotesk** for everything (headlines,
body, labels) plus **Fraunces Italic** as a single deliberate accent word.

**That system is real and intact — just not in `index.html` anymore.** It lives faithfully in:
- `brand/logo/k13-mark.svg`, `k13-mark-cream.svg`, `k13-lockup-horizontal.svg` — all three use
  exactly `#15130F` / `#F1ECE2` (or `#EFE9DC` on the cream variant) / `#FF4F00`, nothing else.
- `brand/print/k13-letterhead-print.html` and `k13-business-card-print.html` — body background
  `#F1ECE2`, ink `#15130F`, accent `#FF4F00`, muted `#6F6755`, and the stylesheet imports
  `Space Grotesk:wght@400;500;700` plus `Fraunces` italic-only for the footer flourish. Print
  masters and logo masters are a genuinely faithful, on-DNA execution of the README.

**`index.html` is a different palette and a different type system entirely.** The stylesheet's
own header comment even names it: `K13 Software Studio · beta_v7 · "THE DRAFTING TABLE"`. Its
`:root` (line 20 on):

```css
--paper:#F3F5FA; --paper-2:#FFFFFF; --paper-3:#E9EDF7;
--ink:#141D35; --ink-2:#2A3554;
--muted:#515C78; --faint:#8089A1;
--blue:#CB4D14; --blue-2:#EA5E14;
--wash-blue:#FCE0CC; --wash-lilac:#E8E1FB; --wash-mint:#D6F0E6; --wash-peach:#FBE6DD;
--disp:"Fraunces",Georgia,serif;
--body:"Inter",system-ui,sans-serif;
--mono:"JetBrains Mono",ui-monospace,monospace;
```

None of the README's five hexes appear anywhere in `index.html`'s `<style>` block (verified by
grep across all `#RRGGBB` literals — the only matches are the beta_v7 tokens plus one status-dot
green `#27B584`, not present in the README either). The paper is a cool blue-grey, not cream; the
ink is navy, not near-black warm ink; the accent is a burnt rust-orange (`#CB4D14`), not the
README's `#FF4F00` signal orange — close in spirit (both orange-family accents) but a materially
different hex, and the README's "Muted" and "Cream on ink" roles don't exist at all in this
palette. **Space Grotesk is not loaded or referenced anywhere in `index.html`** — the Google
Fonts `<link>` pulls Fraunces + Inter + JetBrains Mono only. So the README's claim of "two
families, two voices, nothing else" is now three families, and the one voice (Space Grotesk)
that was supposed to do "all the work" does none of it on the live site. Fraunces *is* still used
as the italic accent voice, consistent with the README's intent — that part of the idea survived
the pivot even though everything around it changed.

`pricing/tiger/index.html` (a client-facing subpage) confirms this isn't a one-off drift on the
homepage: it shares the same `#F3F5FA`/`#141D35`/`#CB4D14` beta_v7 tokens (plus Tiger
Hospitality's own gold accent blended in for that client), so the current site consistently runs
on the Drafting Table system across at least two pages — it just isn't written down anywhere.

**Read on this: the site was deliberately redesigned past the documented kit, and the README
was never updated to match.** This isn't sloppy in-page inconsistency (the live pages are
internally consistent with each other) — it's stale documentation. The logo, letterhead, and
business card are a second, still-valid brand execution that the website itself no longer
speaks.

## Finding 3 — the live visual system judged on its own merits

Setting the README mismatch aside, `index.html`'s actual system (the beta_v7 "Drafting Table"
DNA) reads as deliberate, not accidental:

- **Hierarchy** is clean and consistent: mono uppercase tracked labels (`--mono`, `.eyebrow`,
  `.tag`, `.nl`) for wayfinding/meta → Fraunces display (`--disp`) for headlines and numbers,
  with italic Fraunces in `--blue` used as a single recurring accent motif (hero "obvious.",
  section h2 accent words, card/contact copy) → Inter body for reading copy. Same three-tier
  pattern repeats in the hero status card, work index rows, capability columns, and the contact
  stepper — a real system, not per-section improvisation.
- **Spacing rhythm** is disciplined: every major section uses the same
  `clamp(60px,8vw,110px) 0` vertical padding formula (`.approach`, `.work`, `.cap`, `.about`,
  `.contact` all share it), `.wrap` pins a single `max-width:1200px` with
  `clamp(18px,4vw,56px)` side gutters everywhere, and card/row internal padding stays in a
  tight, related scale (14–30px). This is a real spacing token system even though it's never
  named as one in CSS custom properties — it's expressed only through repeated clamp() literals.
- **Motion** is genuinely well-built: one signature easing (`--ease:cubic-bezier(.22,1,.36,1)`)
  used consistently for every transition in the file — reveals, buttons, hovers, the stepper,
  the parallax clip-path; Lenis smooth scroll; IntersectionObserver-driven `.rv` fade-up
  reveals; a subtle transform-only scroll-depth parallax on the about portrait; a magnetic
  cursor-preview panel on the work index; a rotating status-feed crossfade; count-up stats.
  `prefers-reduced-motion` is handled properly and in two places — a CSS blanket override
  (animation/transition durations collapsed to ~0, `.rv` forced visible) at line 303, and a JS
  `reduced` flag (line 639) that gates Lenis, the count-up, the status-feed rotation, and the
  portrait parallax from ever starting. That's a more thorough reduced-motion path than a single
  CSS media query alone would give.
- **One gap against the house motion DNA** (per the brand-dna-designer brief's own house
  reference, e.g. Miramar/La Vida): those sites reportedly stagger `.rv`-style reveals by index
  (`idx*0.08s`-type delays) so a row of cards/rows cascades in visibly. This site's `.rv` reveal
  has no per-element stagger — every element just fires independently off its own
  IntersectionObserver entry, so cascading is incidental (driven by scroll position, not an
  authored delay) rather than an authored rhythm. Not broken, but a house-DNA element this site
  doesn't currently carry.
- Overall the live system reads as **deliberate and coherent** — it just isn't the system the
  README describes, and it has never been formally specified anywhere (no tokens file, no
  styleguide, only inline clamp()/hex literals in one long `<style>` block).

## What a `public/styleguide.html` would need to cover

Based on the elements `index.html` actually uses (not the README's aspirational list), a DNA
styleguide for this project would need to document, with a live example + spec for each:

- **Colors** — the real beta_v7 token set: `--paper` / `--paper-2` / `--paper-3`, `--ink` /
  `--ink-2`, `--muted` / `--faint`, `--blue` / `--blue-2` (accent), the four wash tints
  (`--wash-blue/-lilac/-mint/-peach`), line tokens (`--line`, `--line-2` at 12%/22% ink alpha),
  `--glass` (62% white), plus the one-off status-green `#27B584` used for the "open" pulse dot —
  currently the only hardcoded color not routed through a variable.
- **Typography** — the true three-family stack (Fraunces display incl. italic-as-accent / Inter
  body / JetBrains Mono labels), weight usage per family, and the italic-accent convention
  (`<i>` inside headlines rendered in `--blue`) as a named pattern, not an incidental one.
  Someone needs to decide and document whether Space Grotesk is retired for good or whether the
  website itself is the thing that needs to be brought back on-brand — that's a brand decision,
  not a styleguide-authoring one.
- **Spacing/layout tokens** — formalize the repeated `clamp()` section-padding and gutter
  formulas into named scale steps; document `.wrap`'s 1200px content width.
- **Motion** — the single `--ease` cubic-bezier, the `.rv` fade-up reveal, the two keyframes
  (`beat` — status pulse, `pop` — send-confirmation ring), the parallax/peek/stepper
  interaction patterns, and the two-layer reduced-motion gate (CSS + JS) as the canonical
  reference implementation.
- **Buttons** — `.btn` (solid, ink-on-hover) and `.btn.ghost` (outline).
- **Forms** — the `.s-field` underline-focus input/textarea pattern used in the contact stepper.
- **Components** — nav (`.nl` underline-sweep), `.card` (numbered, tint swatch), work `.row`
  (hover-reveal thumbnail/underline), `.cap-col` stat stack, glass `.status` card, layered
  `.portrait` parallax figure, multi-step `.stepper` contact flow, footer.
- **Patterns** — the eyebrow + h2 section-header pairing, the italic-accent-word convention, the
  numbered-card convention (01/02/03).

No styleguide currently exists to inherit from, so this would be built from scratch against the
live `index.html`, not adapted from an existing one.
